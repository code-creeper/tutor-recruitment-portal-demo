# Tutor Recruitment Portal · prototype

Interactive, front-end-only prototype of a recruitment and compliance portal for a tuition provider.

- Staff dashboard with pipeline, outstanding references and compliance alerts
- Applicant profiles with stage tracking and activity history
- Automated referee requests, reminders, secure referee form, approve/reject
- Compliance tracking for DBS, right to work and safeguarding, with expiry alerts
- Document uploads, audit log, CSV import/export, GDPR erasure
- Role-based access: Administrator, Recruiter, Compliance Officer, Viewer

All data is fictitious and stored in the browser (localStorage). There is no backend.
Open `index.html` directly or serve the folder with any static host (GitHub Pages works as-is).

The production build is planned on Laravel 12 with a UK-hosted PostgreSQL database.
